# Sistema de Gestión de Biblioteca

## Descripción

Aplicación de escritorio desarrollada en Java para gestionar los libros de una biblioteca.

El proyecto utiliza programación orientada a objetos y Java Swing para la interfaz gráfica.

## Funcionalidades

- Crear libros.
- Mostrar todos los libros.
- Filtrar libros por autor.
- Eliminar libros.
- Validar los datos ingresados.

## Tecnologías

- Java
- Java Swing
- ArrayList
- HashMap
- Git
- GitHub

## Estructura del proyecto

- `Libro`: representa los libros de la biblioteca.
- `Biblioteca`: administra la colección de libros.
- `VentanaPrincipal`: contiene la interfaz gráfica.
- `Main`: inicia la aplicación.
